# Config / mapConstants

Source: `src/config/mapConstants.ts`.

Shared numeric constants for map initialization, lane rendering, hit testing,
overlap heuristics and snap behavior.

Examples:

- `MAP_DEFAULT_CENTER`
- `MAP_DEFAULT_ZOOM`
- `DEFAULT_LANE_HALF_WIDTH`
- lane arrow styling constants;
- hit-test and snap radius constants;
- overlap endpoint tolerances.
