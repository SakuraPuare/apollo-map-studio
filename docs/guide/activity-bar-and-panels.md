# Activity Bar And Panels

The Activity Bar is the fixed icon rail on the left side of the workspace.

## Tabs

| Tab      | Panel                |
| -------- | -------------------- |
| Explorer | `MapOutline`         |
| Layers   | `LayerTree`          |
| Search   | `SearchPanel`        |
| Timeline | `TimelinePanel`      |
| Settings | opens Settings modal |

## MapOutline

Shows entity counts, high-level health information and imported map metadata.

## LayerTree

Shows entities in a tree, supports selection, Road/RSU creation and supported
drag reparenting operations.

## SearchPanel

Searches entity ids/types and selects matches.

## TimelinePanel

Shows undo/redo oriented editing context. It is included in the scene-mode
Dockview layout.
