# Apollo Types

The implementation reference for Apollo entity shapes is
[Types / Apollo](/api/types/apollo).

Use this page when navigating from schema-level docs. The key distinction is:

- proto schema names use Apollo field naming (`stop_sign`, `central_curve`);
- editor entity names use TypeScript discriminators (`stopSign`,
  `centralCurve`).

The bridge between the two is documented at
[IO / proto entity bridge](/api/io/proto-entity-bridge).
